# Development Roadmap - VedxSuper

## Phase 1: Foundation & Authentication
- Setup project structure (`com.vedx.vedxsuper`).
- Integrate/Reuse Angel One Login implementation.
- Implement Session Management.

## Phase 2: Market Data Engine
- Implement WebSocket for live market data.
- Build the Candle Builder.
- Ensure automatic reconnection and low latency.

## Phase 3: Strategy & Indicators
- Implement ATR Indicator.
- Refine SuperTrend Strategy logic (readability & performance).
- Signal generation (BUY / SELL / EXIT).

## Phase 4: Virtual Trading Core
- Virtual execution engine (Paper trading).
- Room Database setup for local storage.
- Trade tracking (Entry, Exit, SL, Target, P&L).

## Phase 5: UI & User Experience
- Dashboard with P&L.
- Trade History screen.
- Settings and Notifications.
- Dark Mode implementation.

## Phase 6: Stability & Optimization
- Performance profiling.
- Bug fixes and stabilization.
- Final documentation.
