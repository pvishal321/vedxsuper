# VedxSuper - Project Vision

## Project Name
VedxSuper

## Tagline
Professional SuperTrend Virtual Trading App

## Mission
Build a lightweight, professional Android trading application focused only on SuperTrend-based virtual trading. This application must remain simple, fast, stable, and easy to maintain.

The goal is not to build an AI platform. The goal is to build the best SuperTrend virtual trading application.

## Core Features (Allowed)
- Angel One Login
- Session Management
- Live Market Data (WebSocket)
- Candle Builder
- ATR Indicator
- SuperTrend Strategy
- BUY / SELL / EXIT Signals
- Virtual Trading
- Trade History
- P&L
- Notifications
- Settings

## Features NOT Allowed
- AI Brain / AI Prediction / Machine Learning
- Fusion Engine / Kafka
- Python Backend / FastAPI
- Shared Memory / Event Bus
- Option Discovery
- Complex Background Services
- Institutional Architecture
- Cloud Processing
- Auto Trading / Real Order Placement

## Purpose
This application is strictly for analysis and paper trading. No real order placement is allowed.

## Long-Term Goal
VedxSuper should become a reliable Android application for SuperTrend-based virtual trading. The application should remain lightweight, maintainable, and production-ready for years without unnecessary complexity. Whenever there is a choice between adding more features or keeping the application simple, always choose simplicity.
